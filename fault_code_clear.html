Engine Maintenance Procedures

PEC FAULT CLEAR

  1. Set both POWER levers to the DISC position.
  2. Set the Condition Lever (CLA) of the engine to be cleared to the FUEL OFF position.
  3. Set the CLA of the other engine to the MIN/850 position.
  4. Set the MAINT DISC switch to MAINT DISC.
  5. Press the RIG TRIM switch to the RIG TRIM position for a minimum of 15 seconds.
  6. Note: The PEC light comes on momentarily on the Central Annunciator Warning Panel (CAWP).
  7. Set the MAINT DISC switch to the OFF position.
  8. Move both CONDITION levers to the FUEL OFF position.

FADEC FAUULT CLEAR

  1. Set the Power Lever (PLA) of the engine to be cleared to the DISC detent.
  2. Set the PLA of the other engine to the FULL REVERSE position.
  3. Set the Condition Lever (CLA) of the engine to be cleared to the MAX/1020 detent.
  4. Set the CLA of the other engine to the FUEL OFF position.
  5. Turn the MAINT DISC switch to ON.
  6. Push the RIG TRIM switch for at least 5 seconds.
  7. Turn the MAINT DISC switch to OFF.
  8. Move both POWER levers to the FLIGHT IDLE detent.
  9. Move both CONDITION levers to the FUEL OFF position.
